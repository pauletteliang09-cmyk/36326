# Corporate Financial Management (36326) Coursework & Exam Review

Interactive open-lecture slides by Phoenix EDU: the coursework case study report (requirements, marking, structure, content recommendations, dos and don'ts), the final exam format, two worked past-paper questions, how to prepare, and FAQ.

## Presenting
| Key | Action |
|---|---|
| ← → / Space | Previous / next slide |
| O | Slide overview |
| F | Full screen |
| P | Pen on/off (H highlighter, E eraser, C clear slide, Esc stop) |
| N | Speaker notes panel (editable) |
| V | Presenter window: notes, timer, next slide; stays in sync with the main window |
| S | Add a sticky note to the current slide |

Drawings, sticky notes and edited speaker notes are saved in your own browser only.

## Access
The page is password-protected: the slides are encrypted (AES-256-GCM, key derived from the password with PBKDF2-SHA256, 600,000 iterations) and are decrypted in the browser only after the correct password is entered. The password is not stored in this repository.
